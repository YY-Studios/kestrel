# PRD: Kestrel

## 목표

직접 차트를 들여다볼 시간이 없는 개인 투자자가, 미리 정해둔 조건에 따라 주식을 자동으로 사고팔 수 있게 한다. 감정·타이밍 놓침으로 규칙이 무너지는 문제를 없앤다.

## 사용자

장중 내내 모니터링할 수 없는 개인 투자자(본인). 매매 규칙은 명확히 갖고 있으나, 그 규칙을 사람이 손으로 집행하다 타이밍을 놓친다.

## 핵심 기능 (MVP)

1. **조건 등록** — 단일 종목 + 단일 조건(예: RSI 30 이하)을 등록할 수 있다.
2. **자동 주문** — 조건이 충족되면 시스템이 모의투자(paper) 계좌로 시장가 주문을 자동 전송한다.
3. **결과 확인** — 체결/실패 결과를 대시보드에서 확인하고, 알림을 받는다.

## MVP 제외 사항

이 항목들은 1차에서 **만들지 않는다.** AI는 이걸 구현하자고 제안하지 마라.

- **실전(real) 매매** — 모의투자(paper)만. 실계좌 주문 로직은 범위 밖.
- 백테스팅, 과거 데이터 시뮬레이션
- 차트·기술적 분석 시각화
- 다중 종목 / 다중 조건 (1종목·1조건 고정)
- 다계좌 / 다증권사 연동 (KIS 단일)
- 손절·익절 자동화 (2차)
- 시세 틱 데이터의 시계열DB 저장 (2차, 그때까지 Supabase PostgreSQL만)
- 사용자 회원가입·다중 사용자 (단일 사용자 전제)

## 성공 지표

- 조건 충족 → 주문 전송까지 지연 3초 이내
- 의도치 않은 오발주 0건
- 모의투자 계좌에서 조건 등록 → 자동 체결 → 결과 확인까지 끊김 없이 동작

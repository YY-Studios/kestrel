# PRD: Kestrel

## 목표

직접 차트를 들여다볼 시간이 없는 개인 투자자가, 미리 정해둔 전략에 따라 미국 주식을 자동으로 사고팔 수 있게 한다. 감정·타이밍 놓침으로 규칙이 무너지는 문제를 없앤다. MVP는 **미국 주식 단기 스윙**을 대상으로 한다.

## 사용자

장중 내내 모니터링할 수 없는 개인 투자자(본인). 추세·눌림목 기반의 단기 스윙 규칙은 명확히 갖고 있으나, 그 규칙을 사람이 손으로 집행하다 타이밍을 놓친다. 미국 정규장 시간대(한국 야간)라 손으로 집행하기가 특히 어렵다.

## 핵심 기능 (MVP) — 시나리오 1 복합 전략

단일 조건이 아니라, 추세 추종 필터 + 눌림목 반등 + 분할매수 + 익절/손절로 구성된 복합 전략을 자동 집행한다.

1. **추세 필터 (진입 자격)** — 후보 종목 중 다음을 만족하는 종목만 매매 대상으로 선별한다.
   - 20일 이동평균선 > 60일 이동평균선
   - 현재가가 60일선 위
2. **눌림목(조정) 포착** — 최근 고점 대비 −5% ~ −10% 하락, 20일선 근처 지지 흐름.
3. **반등 신호 (매수 트리거)** — 아래 중 **2개 이상** 충족 시 매수.
   - RSI 35 이하
   - 볼린저밴드 하단 터치 또는 이탈 후 복귀
   - MACD 히스토그램 반등 조짐
4. **분할매수 (3회)** — 1차 신호 시 자금 40% → 2차 추가 하락 시 30% → 3차 추가 하락 시 30%.
5. **청산** — 익절 +7~10%, 손절 −3~5% (또는 60일선 이탈 시).

주문은 **한국투자(KIS) 해외주식 모의투자(paper) 계좌(해외 리그)**로 자동 전송하고, 체결/실패·분할매수 단계·목표가/손절가까지의 거리를 대시보드에서 확인하며 알림을 받는다.

> **주문 방식 (paper 제약):** KIS 해외주식 **모의투자는 지정가(00)만 가능하고 시장가는 안 된다**(docs/ADR.md ADR-010). 따라서 진입·청산 모두 **지정가**로 주문하되, 현재가를 기준으로 현지 거부를 막기 위한 버퍼(현재가 대비 ±10% 이내)를 둔 가격을 사용한다. 실전(real) 전환 시 시장가 사용 여부는 별도 결정한다.

## 종목 운용 범위 (MVP)

- **후보군**: 사용자가 지정한 워치리스트 **5~10종목**. 이 안에서만 시나리오 1을 평가한다.
- **동시 보유**: 최대 **3 포지션**.

## 화면 (MVP 페이지)

1차 MVP는 아래 8개 화면 + 1개 상세 뷰로 구성한다. 화면별 구성·동작 상세와 시각 기준(목업)은 docs/UI_GUIDE.md "화면 구성"을 따른다.

- **대시보드** — 자산·손익(주가/환차 분리)·전략 ON/OFF·보유 포지션·예수금 경고·다가오는 일정.
- **워치리스트** — 사람이 등록한 감시 종목의 규칙 상태(추세·RSI·볼린저·MACD·신호 N/3). 차트 없이 수치·뱃지.
- **포지션** — 보유 종목 분할매수 단계·평단·손익·목표가/손절가 거리.
- **매매 내역** — 체결 로그(매도는 손절/익절 색 구분), 줄 클릭 시 분석 상세로.
- **손절/익절 분석 상세** — 매매 내역 산하 상세. **1차는 1·2층(사실 기록·규칙 기반 손실 분류)만.** AI 해석(3층)은 **4차**.
- **전략 설정** — 시나리오 1 틀 고정, 임계값만 범위 내 조절(저장=확인, 다음 매매부터 적용).
- **캘린더** — 경제 일정 **읽기 전용**. **자동 매매 연동은 3차**(1차는 인지용).
- **공부** — 전략이 쓰는 지표·용어 **정적 콘텐츠**(AI 실시간 서치 없음).
- **알림** — 새벽 미국장 이벤트 로그(체결·신호·예수금 부족), 헤더 벨로 진입.

> 캘린더(읽기 전용)·공부(정적)는 **1차 MVP에 포함**된다. 단 캘린더의 매매 연동(3차)과 분석 상세의 AI 해석 3층(4차)은 **1차 범위 밖**이다. 차트(캔들/라인 그래프)는 1차에 포함하지 않는다 — 지표는 수치·뱃지로만 표시한다(아래 제외 참고).

## MVP 제외 사항

이 항목들은 1차에서 **만들지 않는다.** AI는 이걸 구현하자고 제안하지 마라.

- **실전(real) 매매** — 모의투자(paper)만. 실계좌 주문 로직은 범위 밖.
- 백테스팅, 과거 데이터 시뮬레이션
- **다중 종목 동시 운용 (위 5~10종목 후보군·3 포지션 한도를 넘는 규모)**
- **종목 자동 발굴 / 스크리닝** — 후보 워치리스트는 사용자가 직접 등록한다.
- 매크로 / 뉴스 기반 진입 (3차 이후)
- 재무 필터 (2차)
- 시세 틱 데이터의 시계열DB 저장 (2차, 그때까지 Supabase PostgreSQL만)
- 다계좌 / 다증권사 연동 (KIS 단일, broker-client로 추상화는 하되 구현체는 KIS만)
- 사용자 회원가입·다중 사용자 (단일 사용자 전제)
- **차트 시각화** — 지표(MA/RSI/볼린저/MACD)는 수치·뱃지로만 표시하고, 실제 차트(캔들·라인 그래프)는 그리지 않는다. MVP 밖.

> 참고: 기존에 제외였던 **분할매수·익절/손절·복합(다중) 지표 평가**는 시나리오 1의 필수 요소이므로 이번 MVP에 **포함**된다.

## 성공 지표

- 반등 신호 충족 → 주문 전송까지 지연 3초 이내
- 의도치 않은 오발주 0건 (paper 계좌 기준 유지)
- 분할매수 단계·평단가·목표가·손절가 상태가 DB와 어긋나지 않음 (상태 불일치 0건)
- 워치리스트 등록 → 추세 필터 통과 → 분할 진입 → 익절/손절 청산까지 끊김 없이 동작

## 운영 시간대 (비기능 요구)

- 거래 대상은 미국 주식이지만 증권사는 한국투자(KIS) 해외주식 API다(docs/ADR.md ADR-010).
- 미국 정규장은 **한국 새벽**에 열린다 — 대략 23:30~06:00, 미국 서머타임 적용 시 22:30~05:00. 따라서 **engine이 새벽 시간대에 가동**돼 있어야 한다.
- **서머타임(DST) 전환을 반드시 처리**한다. 고정 오프셋을 박지 말고 미국 동부 시간 기준으로 장 시간을 계산한다. (구현은 코드 단계)

## 디자인 방향

- 매일 들여다보는 **트레이딩 도구**. 마케팅 페이지가 아니다. (상세는 docs/UI_GUIDE.md)
- 다크 모드 고정, 정보 밀도 우선.
- 미국 시장 관습을 따른다: **상승=초록, 하락=빨강** (한국과 반대 — docs/UI_GUIDE.md).

# UI 디자인 가이드

## 디자인 원칙

1. **도구처럼 보여야 한다.** 마케팅 랜딩이 아니라 매일 들여다보는 트레이딩 대시보드다. 첫인상보다 반복 사용 시의 가독성·정보 밀도가 우선.
2. **숫자가 주인공.** 가격·수익률·체결 상태가 한눈에 읽혀야 한다. 장식이 숫자를 가리지 않는다.
3. **상태가 즉시 읽힌다.** 조건 활성/대기, 주문 성공/실패가 색과 위치만으로 구분된다. 텍스트를 읽지 않아도 알 수 있게.
4. **다크 모드 고정.** 장시간 모니터링 도구의 표준. 라이트 모드는 만들지 않는다.

## AI 슬롭 안티패턴 — 하지 마라

| 금지 사항 | 이유 |
| --- | --- |
| `backdrop-filter: blur()` (glass morphism) | AI 템플릿의 가장 흔한 징후 |
| 배경 그라데이션 텍스트 (gradient-text) | AI가 만든 SaaS 랜딩의 1번 특징 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 단일 네온 액센트(acid-green/형광) 떡칠 | 다크 배경 + 형광 포인트 하나도 AI 다크테마 클리셰. 색은 도메인(등락)에서 가져온다 |
| `box-shadow` 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 모든 카드 동일한 `rounded-2xl` | 균일한 큰 둥근 모서리는 템플릿 느낌. 도구는 각지게 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩에 있는 장식 |
| "Powered by AI" 류 배지 | 기능 아닌 장식 |

## 색상

### 등락/매매 색상 — 미국 시장 관습 (중요)

> **미국 주식은 상승·이익이 초록, 하락·손실이 빨강이다.** 한국 관습(상승=빨강)과 정반대. 이 프로젝트는 미국 주식을 다루므로 **초록=상승**으로 짠다. 한국식 빨강=상승으로 짜지 마라.

| 용도 | 값 |
| --- | --- |
| 상승 / 매수 / 이익 | `#22C55E` (초록) |
| 하락 / 매도 / 손실 | `#EF4444` (빨강) |
| 보합 / 변화 없음 | `#787B86` (회색) |

### 상태(시맨틱) 색상

등락색이 초록·빨강을 가져갔으므로, 상태색은 초록·빨강을 피해 **청/주황 계열**로 분리한다.

| 용도 | 값 |
| --- | --- |
| 성공 / 체결 완료 | `#2962FF` (파랑) |
| 에러 / 주문 실패 | `#F97316` (주황) |
| 경고 / 대기 | `#FACC15` (노랑) |

> **주의 1 (등락색 ≠ 상태색).** 등락은 초록(`#22C55E`)·빨강(`#EF4444`), 상태는 파랑·주황·노랑이다. 같은 빨강/초록을 두 의미로 쓰지 않는다. "이 빨강이 손실이야, 주문 실패야?" 혼동을 없앤다.
> **주의 2 (파랑은 상태 성공 전용).** `#2962FF`(파랑)는 체결 성공 상태에만 쓴다. 등락색이나 지표선(이동평균선 등 차트 보조선)에는 파랑을 쓰지 마라 — 의미가 겹쳐 혼동된다.

### 지표선(차트 보조선) 색상

차트 시각화 자체는 MVP 밖(docs/PRD.md)이지만, 향후 지표선(이동평균·볼린저 등) 표시를 대비해 팔레트만 미리 정의해 둔다. 등락색(초록·빨강)·상태색(파랑·주황·노랑)과 **겹치지 않는** 무채도/중성 계열로 둔다.

| 용도 | 값 |
| --- | --- |
| 이동평균 20일선 | `#26A69A` (청록 — 상태 파랑과 다름) |
| 이동평균 60일선 | `#A1887F` (토프/회갈 — 주황과 다름) |
| 볼린저밴드·기타 보조선 | `#9AA0A8` (회색조) |

> **주의 3 (지표선 색 제약).** 지표선에는 **보라·인디고를 쓰지 않는다** — AI 슬롭 안티패턴(아래 표)과 충돌한다. 파랑(`#2962FF`)도 상태 전용이라 금지(주의 2). 지표선은 위 청록·토프·회색조 안에서만 고른다.

## 컴포넌트

- **카드/패널**: `rounded-md bg-[#16181D] border border-[#262A33] p-4` — 큰 라운드 금지, 도구답게 절제.
- **숫자 표시**: 등미·monospace 계열 폰트로 자릿수 정렬. 가격·수익률은 항상 등락색 적용.
- **버튼**
  - Primary: `rounded-md bg-[#E8EAED] text-[#0E0F12] hover:bg-white`
  - Text: `text-[#787B86] hover:text-[#E8EAED]`
  - 위험 액션(주문 관련): 색만으로 강조하지 말고 라벨로 명시 ("모의투자 매수" 처럼 paper/real을 항상 표기)
- **입력 필드**: `rounded-md bg-[#0E0F12] border border-[#262A33] px-3 py-2`
- **상태 뱃지**: 작은 점(dot) + 라벨. 감시 중(활성)=노랑(`#FACC15`) 점, 비활성=회색 점. 체결 성공=파랑(`#2962FF`) 점, 주문 실패=주황(`#F97316`) 점. 등락 초록·빨강은 뱃지에 쓰지 않는다(가격 전용).

## 시나리오 1 화면 요소

단일 조건이 아니라 복합 전략이므로, "지금 이 종목이 전략의 어느 단계인지"가 한눈에 읽혀야 한다.

- **복합 신호 현황**: 반등 신호 3가지(RSI ≤35 / 볼린저 하단 / MACD 반등) 중 **충족 개수**를 표시한다(예: `2/3 충족`). 2개 이상이면 매수 트리거. 개별 신호는 충족=강조, 미충족=비활성 텍스트색으로 구분.
- **추세 필터 상태**: 20일선 > 60일선 & 현재가 > 60일선 통과 여부를 통과/미통과 뱃지로. 미통과면 애초에 매매 후보가 아님을 명확히.
- **분할매수 단계**: `1/3`·`2/3`·`3/3`로 현재 진입 회차를 표시한다. 투입 비중(40/30/30%)과 평단가를 함께.
- **목표가 / 손절가 거리**: 현재가에서 익절 목표가·손절가까지 남은 거리(% 또는 가격)를 등락색으로. 목표가 방향=초록, 손절 방향=빨강.
- 주문 관련 표기는 항상 **"모의투자(paper)"**임을 명시한다(실전과 헷갈리지 않게).

## 화면 구성

8개 주요 화면 + 1개 상세 뷰로 구성된다. **시각 기준은 목업 파일 [`docs/ui-mockups/kestrel-ui-mockups.html`](ui-mockups/kestrel-ui-mockups.html)** (탭 전환형) — 레이아웃·정보 밀도·구성요소 배치를 그 목업으로 참조하라.

> **색상 주의.** 목업의 색상 hex(예: 상승 `#26A69A`, 하락 `#F23645`, 경고 `#FFA726`)는 **레이아웃·밀도 확인용 예시값**이다. 실제 색상은 위 "색상" 절의 **정식 팔레트가 권위**다 — 구현 시 상승 `#22C55E` / 하락 `#EF4444` / 경고 `#FACC15`로 매핑한다. (`#26A69A`는 정식 팔레트에서 20일 이동평균 지표선 전용이므로 등락색으로 쓰지 않는다.) 목업과 이 문서가 색에서 어긋나면 이 문서를 따른다.

각 화면은 **목적 / 주요 구성요소 / 핵심 동작** 순으로 적는다.

### 1. 대시보드
- **목적**: 자산·손익·전략 상태를 한 화면에서 즉시 파악. 매일 첫 진입 화면.
- **구성요소**: 상단 지수·환율 띠(DOW·NASDAQ·S&P500·원/달러) / 자산 카드(총 평가자산·예수금·보유 한도 N/3) / 손익 카드(총손익, **주가손익·환차손익 분리**, 오늘 손익) / 시나리오 1 전략 카드 / 보유 포지션 요약 카드 / 예수금 부족 경고(주황) / 다가오는 주요 일정 위젯.
- **핵심 동작**: 전략 **ON·OFF 토글**(켤 때 확인 단계). 예수금 부족 시 미체결 신호를 주황 경고로 노출. 일정 위젯은 캘린더로 연결.

### 2. 워치리스트
- **목적**: 사람이 직접 채운 감시 종목의 규칙 상태를 한눈에. (시장 전체 스캔이 아님)
- **구성요소**: 종목 행마다 현재가 + 뱃지(추세 통과 여부 / RSI / 볼린저 / MACD / 신호 N/3). **차트 없음 — 수치·뱃지로만.** "종목 추가" 버튼.
- **핵심 동작**: **추세 미통과(20일선<60일선) 종목은 흐리게 + 후보에서 제외.** "추세 필터는 이 목록 안에서만 작동(시장 스캔 아님)" 문구 노출. 행 클릭 시 규칙 상태 상세.

### 3. 포지션
- **목적**: 보유 종목의 진행 상태(분할매수·손익·청산 거리) 추적.
- **구성요소**: 종목별 분할매수 단계(`N/3`, 회차별 비중 40/30/30)·평단·수량·손익 / **손절가―현재가―목표가 막대(현재가 위치 마커)** / 손절·목표까지 거리(%).
- **핵심 동작**: 표시 전용(주문은 engine 자동). 보유/한도(N/3) 노출.

### 4. 매매 내역
- **목적**: 체결 로그 확인 + 개별 거래 상세로의 진입점.
- **구성요소**: 시간순 체결 목록(종목·구분·유형·체결가·손익). **매도는 손절/익절을 색으로 구분**(손절=빨강, 익절=초록). 전체/매수/매도 필터.
- **핵심 동작**: **각 줄 클릭 → 손절/익절 분석 상세(5번)로** 이동.

### 5. 손절/익절 분석 상세
- **목적**: 한 거래가 왜 그렇게 끝났는지 사실·규칙 기반으로 복기. **독립 메뉴가 아니라 매매 내역 산하 상세 뷰.**
- **구성요소(3층 구조)**:
  - **1층 · 사실 기록(확정, AI 아님)**: 진입가·진입 근거(충족 신호)·청산·보유 기간·진입 후 최고가·분할매수 상태.
  - **2층 · 손실 유형(규칙 기반 분류, AI 아님)**: whipsaw(진입 직후 하락)·고점 후 하락·추세 이탈·시장 동반 하락 등으로 결정론적 분류.
  - **3층 · AI 참고 의견(추정)**: **4차 기능.** 점선·회색 박스 + 경고문("AI 추정, 검증된 사실 아님")으로 명확히 격리. **1차에는 1·2층만 보인다.**
- **핵심 동작(진입 경로 3개)**: ① 매매 내역 줄 클릭 ② 손절 알림 클릭 ③ 포지션이 청산되면 해당 카드가 분석 상세로 전환.

### 6. 전략 설정
- **목적**: 시나리오 1의 임계값을 안전 범위 안에서 조절.
- **구성요소**: **시나리오 1 틀은 고정**, 임계값만 조절(RSI 과매도 기준·신호 충족 개수·익절 목표·손절선). **각 값에 범위 제한**(예: RSI 25~45, 손절 −1~−10%) — 슬라이더/선택지로 범위 밖 입력 차단.
- **핵심 동작**: **저장 = 확인 단계.** "값 변경은 **다음 매매부터 적용, 진행 중인 포지션엔 영향 없음**" 명시. 기본값 복원.

### 7. 캘린더
- **목적**: 새벽 미국장 전 주요 경제 일정 인지.
- **구성요소**: **읽기 전용** 일정(실적·CPI·PPI·FOMC), 영향도(고/중) 뱃지, 보유 종목 관련 일정 강조.
- **핵심 동작**: 보기만. **"자동 매매 연동은 3차" 명시**(1차는 인지용 읽기 전용).

### 8. 공부
- **목적**: 우리 전략이 쓰는 지표·용어를 초보자용으로 정리.
- **구성요소**: **정적 콘텐츠** — 전략이 쓰는 지표(RSI·볼린저·MACD·이동평균선) + 기본 용어(눌림목·분할매수·손절/익절·평단가).
- **핵심 동작**: 읽기 전용. **AI 실시간 서치 없음**(정적 문서).

### 9. 알림
- **목적**: 새벽 미국장에 사람이 못 보는 사이 일어난 일을 시간순으로 전달.
- **구성요소**: 이벤트 로그(체결·매수 신호·예수금 부족 등), 시간순, **색 구분**(손절=빨강·신호/경고=주황·체결=초록). 읽음 처리.
- **핵심 동작**: 손절/익절 알림 클릭 → 분석 상세(5)로 연결. (헤더 벨 아이콘으로 진입 — 아래 네비게이션 참고)

## 네비게이션 구조

- **좌측 사이드바 — 3그룹**:
  - **[메인]** 대시보드
  - **[매매]** 워치리스트 · 포지션 · 매매 내역 · 전략 설정
  - **[정보]** 캘린더 · 공부
- **알림은 사이드바가 아니라 헤더 우측 벨 아이콘**(미읽음 배지). 헤더에는 **paper/real 표기**와 **엔진 상태**도 고정 노출.
- **손절/익절 분석은 매매 내역 산하 상세 뷰**다(별도 메뉴 아님).

## 레이아웃

- 전체 너비: `max-w-6xl` (대시보드는 넓게)
- 정렬: 좌측 정렬 기본. 데이터 테이블은 숫자 우측 정렬.
- 간격: `gap-3~4`, 섹션 간 `space-y-6`
- 밀도: 여백보다 정보. 한 화면에 조건·시세·체결을 같이 보이게.

| 숫자(가격/수익률) | `text-lg font-mono` + 등락색 |
| 본문 | `text-sm text-[#B0B4BC]` |

## 카피(문구)

- 사용자가 제어하는 말로 쓴다: "조건 추가", "매수 조건", "체결 내역" — 시스템 용어("webhook", "polling") 금지.
- 액션은 끝까지 같은 이름: "매수 조건 등록" 버튼 → "등록됨" 토스트.
- **paper/real을 항상 표기**한다. 주문 관련 UI엔 "모의투자"임을 명시해 실전과 헷갈리지 않게.
- 빈 화면·에러는 다음 행동을 안내한다. "조건이 없습니다 → 첫 매수 조건을 등록하세요."

## 애니메이션

- 허용: fade-in (0.3s), 값 변경 시 색 깜빡임(짧게).
- 그 외 모든 장식 애니메이션 금지. 특히 글로우·플로팅·패럴럭스.

## 아이콘

- SVG 인라인, `strokeWidth 1.5`.
- 아이콘을 둥근 배경 박스로 감싸지 않는다.

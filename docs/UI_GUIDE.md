# UI 디자인 가이드

## 디자인 원칙

1. **도구처럼 보여야 한다.** 마케팅 랜딩이 아니라 매일 들여다보는 트레이딩 대시보드다. 첫인상보다 반복 사용 시의 가독성·정보 밀도가 우선.
2. **숫자가 주인공.** 가격·수익률·체결 상태가 한눈에 읽혀야 한다. 장식이 숫자를 가리지 않는다.
3. **상태가 즉시 읽힌다.** 조건 활성/대기, 주문 성공/실패가 색과 위치만으로 구분된다. 텍스트를 읽지 않아도 알 수 있게.
4. **다크 모드 고정.** 장시간 모니터링 도구의 표준. 라이트 모드는 만들지 않는다.

## AI 슬롭 안티패턴 — 하지 마라

| 금지 사항 | 이유 |
| --- | --- |
| `backdrop-filter: blur()` (glass morphism) | AI 템플릿의 가장 흔한 징후 |
| 배경 그라데이션 텍스트 (gradient-text) | AI가 만든 SaaS 랜딩의 1번 특징 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 단일 네온 액센트(acid-green/형광) 떡칠 | 다크 배경 + 형광 포인트 하나도 AI 다크테마 클리셰. 색은 도메인(등락)에서 가져온다 |
| `box-shadow` 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 모든 카드 동일한 `rounded-2xl` | 균일한 큰 둥근 모서리는 템플릿 느낌. 도구는 각지게 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩에 있는 장식 |
| "Powered by AI" 류 배지 | 기능 아닌 장식 |

## 색상

### 등락/매매 색상 — 한국 시장 관습 (중요)

> **한국 주식은 상승·매수가 빨강, 하락·매도가 파랑이다.** 서구 관습(상승=초록)과 정반대. 절대 초록=상승으로 짜지 마라.

| 용도 | 값 |
| --- | --- |
| 상승 / 매수 / 이익 | `#F23645` (빨강) |
| 하락 / 매도 / 손실 | `#2962FF` (파랑) |
| 보합 / 변화 없음 | `#787B86` (회색) |

### 배경

| 용도 | 값 |
| --- | --- |
| 페이지 | `#0E0F12` |
| 카드 / 패널 | `#16181D` |
| 경계선 | `#262A33` |

### 텍스트

| 용도 | 값 |
| --- | --- |
| 주 텍스트 (숫자·제목) | `#E8EAED` |
| 본문 | `#B0B4BC` |
| 보조 / 라벨 | `#787B86` |
| 비활성 | `#4A4E57` |

### 상태(시맨틱) 색상

| 용도 | 값 |
| --- | --- |
| 성공 / 체결 완료 | `#26A69A` (청록 — 등락 빨강·파랑과 구분) |
| 에러 / 주문 실패 | `#EF5350` |
| 경고 / 대기 | `#FFA726` |

> 주의: 체결 성공을 "초록"으로 쓰되 등락의 빨강·파랑과 헷갈리지 않게 청록 계열(`#26A69A`)을 쓴다. 상태색과 등락색은 의미가 다르므로 팔레트를 분리한다.

## 컴포넌트

- **카드/패널**: `rounded-md bg-[#16181D] border border-[#262A33] p-4` — 큰 라운드 금지, 도구답게 절제.
- **숫자 표시**: 등미·monospace 계열 폰트로 자릿수 정렬. 가격·수익률은 항상 등락색 적용.
- **버튼**
  - Primary: `rounded-md bg-[#E8EAED] text-[#0E0F12] hover:bg-white`
  - Text: `text-[#787B86] hover:text-[#E8EAED]`
  - 위험 액션(주문 관련): 색만으로 강조하지 말고 라벨로 명시 ("모의투자 매수" 처럼 paper/real을 항상 표기)
- **입력 필드**: `rounded-md bg-[#0E0F12] border border-[#262A33] px-3 py-2`
- **상태 뱃지**: 작은 점(dot) + 라벨. 활성=빨강 점, 대기=회색 점.

## 레이아웃

- 전체 너비: `max-w-6xl` (대시보드는 넓게)
- 정렬: 좌측 정렬 기본. 데이터 테이블은 숫자 우측 정렬.
- 간격: `gap-3~4`, 섹션 간 `space-y-6`
- 밀도: 여백보다 정보. 한 화면에 조건·시세·체결을 같이 보이게.

## 타이포그래피

| 용도 | 스타일 |
| --- | --- |
| 페이지 제목 | `text-2xl font-semibold text-[#E8EAED]` |
| 패널 제목 | `text-xs font-medium uppercase tracking-wide text-[#787B86]` |
| 숫자(가격/수익률) | `text-lg font-mono` + 등락색 |
| 본문 | `text-sm text-[#B0B4BC]` |

## 카피(문구)

- 사용자가 제어하는 말로 쓴다: "조건 추가", "매수 조건", "체결 내역" — 시스템 용어("webhook", "polling") 금지.
- 액션은 끝까지 같은 이름: "매수 조건 등록" 버튼 → "등록됨" 토스트.
- **paper/real을 항상 표기**한다. 주문 관련 UI엔 "모의투자"임을 명시해 실전과 헷갈리지 않게.
- 빈 화면·에러는 다음 행동을 안내한다. "조건이 없습니다 → 첫 매수 조건을 등록하세요."

## 애니메이션

- 허용: fade-in (0.3s), 값 변경 시 색 깜빡임(짧게).
- 그 외 모든 장식 애니메이션 금지. 특히 글로우·플로팅·패럴럭스.

## 아이콘

- SVG 인라인, `strokeWidth 1.5`.
- 아이콘을 둥근 배경 박스로 감싸지 않는다.
